# 🕌 QML Athan Times API

A **Qt/QML** application that retrieves and displays daily Islamic prayer times using a REST API.

This project demonstrates the integration of **C++** and **QML** to build a responsive graphical application, including asynchronous HTTP requests, JSON parsing and REST API communication.

## ✨ Features

* Display daily prayer times
* Retrieve data from a REST API
* Responsive Qt Quick (QML) interface
* C++ backend integrated with QML
* Asynchronous network requests
* JSON parsing

## 🛠️ Technologies

* C++
* Qt
* Qt Quick (QML)
* Qt Network
* Qt JSON
* REST API

## 🚀 Getting Started

### Requirements

* Qt Creator
* Qt 6 (or the version used by the project)
* A C++ compiler (MSVC, MinGW or GCC)

### Build & Run

1. Clone the repository:

```bash
git clone https://github.com/bAbderraouf/Qml_AthanTimes_API.git
```

2. Open the project in **Qt Creator** (`.pro` or `.qmlproject`, depending on the project).

3. Select the appropriate Qt Kit.

4. Build and run the application.
